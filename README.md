## ایده اصلی
گاهی گوش دادن به کلاس‌ها مخصوصاً زمانی که طولانی می‌شوند یا تعامل را از دست می‌دهند می‌تواند خسته‌کننده باشد. این پروژه قصد دارد یک رابط کاربری ساده برای درس اپتیک ارائه دهد. شاید جزوه‌ای برای مرور، شاید پروژه‌ای از روی بیکاری؛ ...

## تکنولوژی‌ها
برای سبک نگه داشتن پروژه و عدم نیاز به سرور، فعلاً فقط از وب استاندارد استفاده شده است:
- HTML5
- CSS3 (بدون فریم‌ورک سنگین)
- Vanilla JavaScript
