# Optic-Nameh
> **تبدیل کیس‌استادی‌ها به مینی‌اپ‌های HTML برای یادگیری ساده‌تر**

![Status](https://img.shields.io/badge/Status-Alpha-orange)
![License](https://img.shields.io/badge/License-MIT-blue)

---
## ایده اصلی
خواندن کیس‌استادی‌های (Study Cases) طولانی و متنی می‌تواند خسته‌کننده باشد. این پروژه تلاش می‌کند تا با تبدیل این متون به **مینی‌اپ‌های سبک HTML** و استفاده از یک **UI ساده و متمرکز**، تجربه یادگیری را تعاملی‌تر و قابل‌هضم‌تر کند.

## تکنولوژی‌ها
برای سبک نگه داشتن پروژه و عدم نیاز به سرور، فعلاً فقط از وب استاندارد استفاده شده است:
- HTML5
- CSS3 (بدون فریم‌ورک سنگین)
- Vanilla JavaScript

## نحوه اجرا
از آنجا که پروژه بر پایه HTML است، نیازی به بیلد یا نصب پکیج نیست:
1. مخزن را کلون یا دانلود کنید:
```bash
git clone https://github.com/[YourUsername]/[YourRepoName].git
```
2. فایل `index.html` را مستقیماً در مرورگر خود باز کنید.

## ساختار فعلی

